# wxpusher-integration v1.0.3

用于为现有脚本、后端服务和自动化任务接入 WxPusher 通知的 Agent Skill。
覆盖标准推送、UID/Topic、SPT、成功判断、凭据配置和故障排查。

## 本次变化

- 采用 MIT 许可证，独立安装的 skill 目录也包含完整许可文本。
- 补充面向使用者的安装说明、维护流程和自动检查配置。
- API 事实、触发范围及既有授权语义保持不变；API 资料最近核验于 2026-10-06。

## 安装

下载附件 `wxpusher-integration-1.0.3.zip`，解压后将其中的
`wxpusher-integration` 文件夹复制到宿主支持的 skills 目录。
Codex 用户级目录为 `~/.agents/skills/`。
已有同名目录时先备份，再安装完整的新版本，避免旧文件残留。

Skill 本体是 Markdown/YAML 文件，不需要安装 Python 或 PowerShell；
这些依赖仅供仓库维护工具使用。安装完成后可向代理提出：

> 使用 wxpusher-integration，为现有脚本接入 WxPusher 通知；凭据先使用环境变量占位，完成离线验证。
