# wxpusher-integration v1.0.4

用于为脚本、后端服务、定时任务和 CI 接入或排查 WxPusher 通知的 Agent Skill。
覆盖标准推送、UID/Topic、SPT、响应判断、凭据配置和故障处理，主要使用简体中文。

## 本次变化

- 明确触发范围：用户指定 WxPusher，或上下文已选定该服务时使用；通用 UID、Topic 和未选服务商的微信通知需求不单独触发。
- 整理中文入口、请求示例和参考资料索引，减少混合术语，便于按任务读取。
- 补齐微信 ClawBot（iLink）的绑定、启用、激活和接收限制，说明其不支持上行消息及任意好友或微信群发送。
- 修正部分 API 来源归因和故障诊断表述，保留 SPT 撤销、双目标字段和付费筛选等未确认行为的边界。

逐目标业务结果、API 接受与实际收到的区别、有限重试及既有用户授权语义继续保留。
官方 API 资料最近核验于 **2026-10-08**；本次发布不刷新该核验日期。

## 安装

下载附件 `wxpusher-integration-1.0.4.zip`，解压后将完整的
`wxpusher-integration` 文件夹复制到宿主支持的 skills 目录。
Codex 用户级目录为 `~/.agents/skills/`；已有同名目录时先备份，再安装完整的新版本。

也可从当前 GitHub 安装源安装：

```sh
npx skills add hunxuankai/wxpusher-integration --skill wxpusher-integration
```

Skill 本体仅包含 Markdown/YAML，没有 Python、Node.js 或 PowerShell 运行时依赖。
执行集成任务时使用代理宿主已有的文件、HTTP 和开发工具；真实推送需要使用者自己的
WxPusher 配置，并遵循对用途、对象和频率的明确授权。
